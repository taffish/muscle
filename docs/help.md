# muscle Help

MUSCLE 5 makes multiple sequence alignments, alignment ensembles, and
Reseek-based structure alignments.

Usage:
  taf-muscle [-h | --help]
  taf-muscle [-v | --version]
  taf-muscle [MUSCLE_ARGS...]
  taf-muscle -- [MUSCLE_ARGS...]
  taf-muscle COMMAND [ARGS...]
  taf-muscle --compile [ARGS...]

Wrapper options:
  -h, --help       Show this TAFFISH app help
  -v, --version    Show TAFFISH package version
  --compile        Print generated shell code instead of running it
  --               Stop wrapper option parsing and pass following args to muscle

Default upstream command:
  taf-muscle -- -version
  taf-muscle -- -h
  taf-muscle -- -align input.fa -output aln.afa
  taf-muscle -- -super5 input.fa -output aln.afa
  taf-muscle -- -align input.fa -diversified -replicates 100 -output ensemble.efa
  taf-muscle -- -maxcc ensemble.efa -output maxcc.afa
  taf-muscle -- -efa_explode ensemble.efa

Command mode:
  taf-muscle muscle -version
  taf-muscle muscle -align input.fa -output aln.afa

Structure-alignment input:
  MUSCLE 5.3 supports mega inputs generated by Reseek:
    taf-muscle -- -align structs.mega -output structs.afa
    taf-muscle -- -super7 structs.mega -distmxin structs.distmx -reseek -output structs.afa

Notes:
  This app builds MUSCLE 5.3 from the upstream source tag with a small Linux
  aarch64 platform-macro patch and without -march=native. Native container
  platforms are linux/amd64 and linux/arm64. The static binary reports:
    muscle 5.3.linux64 [v5.3-taffish-r1]
  The runtime image contains the single static muscle executable plus upstream
  docs/license/version markers; build-only helpers are not shipped.

Boundaries:
  This app packages MUSCLE only. It does not bundle Reseek, tree-building tools,
  downstream phylogenetic tools, PDB/mmCIF download helpers, or benchmark data.
